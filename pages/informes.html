📄 Informes y Exportación de Datos

Cómo generar informes y exportar información en Dolibarr

📊 Informes en Dolibarr

Dolibarr permite generar informes de dos tipos: documentos en PDF (facturas, presupuestos, albaranes...) y listados exportables en Excel o CSV con datos de clientes, productos, pedidos, etc.

Los informes son muy útiles para llevar un control del negocio: saber cuánto se ha facturado en un mes, qué productos tienen poco stock, cuántos pedidos hay pendientes, etc.

💡 Para acceder a los informes hay que tener el módulo correspondiente activado y tener permisos de lectura sobre ese módulo.

📋 Tipos de informes disponibles

MóduloInformes disponiblesFormato
FacturaciónFacturas emitidas, facturas pendientes, resumen por clientePDF / Excel
PresupuestosPresupuestos enviados, aceptados, rechazadosPDF / Excel
AlmacénStock actual, movimientos, productos bajo mínimoPDF / Excel
Terceros (clientes)Listado de clientes, ficha de clientePDF / Excel / CSV
RRHHInforme de gastos, días libres solicitadosPDF
ContabilidadBalance, cuenta de resultados, libro diarioPDF / Excel

📤 Exportar información

Dolibarr tiene una herramienta de exportación que permite sacar cualquier listado de datos en formato Excel o CSV para trabajar con ellos en otros programas.

Se accede desde Utilidades → Exportar. Desde ahí se elige el tipo de datos a exportar (clientes, facturas, productos...) y los campos que queremos incluir.

1

Ir a Utilidades → Exportar

En el menú principal de Dolibarr, acceder a la sección de exportación.

2

Elegir el tipo de datos

Seleccionar qué queremos exportar: clientes, facturas, productos, pedidos...

3

Seleccionar los campos

Elegir qué columnas queremos que aparezcan en el archivo exportado.

4

Aplicar filtros (opcional)

Filtrar por fechas, por estado, por cliente, etc. para exportar solo los datos que interesan.

5

Descargar el archivo

Elegir el formato (Excel o CSV) y descargar el archivo al ordenador.

📥 Importar datos

Dolibarr también permite importar datos desde un archivo CSV o Excel. Esto es muy útil cuando se migra de otro sistema y hay que cargar los clientes, productos o el histórico de facturas.

Se accede desde Utilidades → Importar. El proceso es similar al de exportar: se elige el tipo de datos, se sube el archivo y Dolibarr intenta hacer la correspondencia entre las columnas del archivo y los campos del sistema.

Antes de importar datos en producción es recomendable hacer una prueba con pocos registros para verificar que los campos se mapean correctamente.
